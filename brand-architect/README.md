# Skill Brand Architect — Installation

Skill Claude permettant de construire son Brand Book complet de freelance en une session conversationnelle de 45-60 min.

## Installation

### Option 1 — Skill projet (recommandé pour usage personnel)

1. Crée un projet Claude (ou ouvre un projet existant dédié au branding)
2. Place le dossier `skill-brand-architect/` dans le répertoire `.claude/skills/` du projet
3. Le skill s'active automatiquement dès que tu mentionnes branding, positionnement, identité de marque, etc.

### Option 2 — Skill global (pour tous tes projets Claude Code / Claude Desktop)

Copie le dossier dans `~/.claude/skills/` sur ton système.

### Option 3 — Skill organisation (à partager avec ton équipe ou tes viewers)

Upload le dossier via les paramètres admin de Claude Enterprise ou distribue le fichier `SKILL.md` pour installation manuelle.

## Déclenchement automatique

Le skill s'active dès que l'utilisateur mentionne :

- Branding, identité de marque, positionnement freelance
- Brand book, tagline, archétype de marque, ton de voix
- ICP, client idéal, promesse unique, manifeste de marque
- "Je lance mon activité", "je me différencie", "mon positionnement"
- "Construire ma marque perso", "je ne sais pas comment me présenter"
- "Aide-moi à définir qui je suis professionnellement"

## Utilisation

1. Lance une conversation avec Claude
2. Dis simplement : *"Aide-moi à construire mon identité de marque de freelance"* (ou toute variante)
3. Claude déclenche automatiquement le skill et lance la Phase 0 (calibration)
4. Suis les 8 phases en répondant aux questions
5. À la fin, tu reçois ton Brand Book complet + 3 actions concrètes à 7 jours

## Livrable

Brand Book en 8 blocs :

1. Positionnement (phrase "J'aide X à Y grâce à Z")
2. ICP (client idéal précis)
3. Promesse unique
4. Valeurs (3 max, testables par un "non")
5. Ton de voix (3 adjectifs + 2 à bannir)
6. Archétype de marque (parmi les 12 de Jung/Mark & Pearson)
7. Tagline (max 7 mots)
8. Manifeste (5 lignes)

## Durée

45-60 min en une session.
