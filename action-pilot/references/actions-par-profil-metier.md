# Catalogue d'actions par profil métier × levier — Phase 4

> Ces catalogues sont des **points de départ**, pas des recettes. Tu adaptes systématiquement aux réponses de Phase 1 (tarification, volume, reach, contraintes). Règle d'or : toute action que tu proposes doit être **rattachable à une réponse Phase 1** ; sinon tu la retires.
>
> Structure cible du plan 30 jours :
> - **S1** (J+1 → J+7) : 1 action/jour, ≤ 1h chacune (7 actions totales)
> - **S2** (J+8 → J+14) : 3 actions, 2-4h chacune
> - **S3** (J+15 → J+21) : 3 actions
> - **S4** (J+22 → J+30) : 3 actions + check-point
> - Plafond total : 12 actions (ajuster à la baisse si Q5 ≤ 3h/semaine)

---

## LEVIER TEMPS — Logique générique (4 sous-thèmes)

Quel que soit le profil métier, le plan TEMPS s'articule autour de 4 leviers concrets :

1. **Pricing** — auditer, repositionner, augmenter, signaler
2. **Process** — rationaliser, standardiser, templatiser le cycle client
3. **Automatisation non facturable** — prospection, facturation, onboarding, relance
4. **Commercial actif** — remplir le pipeline en haut de gamme

### Répartition type TEMPS (universelle)

- **S1 — Diagnostic & premier signal** : auditer la réalité (qui paie quoi, combien de temps, quelle marge) + 1 action de signal prix (annonce tarif nouveau, prise de contact premium, refus d'une mission low-margin).
- **S2 — Standardisation** : template de proposition commerciale, contrat-type, onboarding doc, rationalisation du livrable.
- **S3 — Automatisation** : 1 automation pour 1 tâche non facturable (prospection tiède, suivi client, facturation récurrente).
- **S4 — Réactivation commerciale** : reprise de contact avec 10 clients qualifiés, pitch premium, proposition de packaging.

### S3 (3 actions)

### S4 (3 actions + check-point)

- Publication d'1 post "avant/après" sur un projet récent montrant le gain de temps IA (si Stack Blueprint fait, aligner avec Niveau 2).
- Discussion directe avec 1 client sur proposition de partenariat récurrent (rétainer, TMA, abonnement mensuel).
- J+30 : check-point (TJM moyen sur les nouvelles offres signées, pipeline, marge horaire).

## LEVIER INVESTISSEMENT — Logique générique (4 sous-thèmes)

Quel que soit le profil métier, le plan INVESTISSEMENT s'articule autour de 4 piliers :

1. **Validation du concept d'asset** (est-ce que le marché le veut ?)
2. **Canal de capture audience** (sans audience, pas de produit)
3. **Asset minimal viable** (ne pas construire une Ferrari, un scooter qui roule suffit pour tester)
4. **Soft launch + pricing** (vendre avant que le produit soit parfait)

### Répartition type INVESTISSEMENT (universelle)

- **S1 — Validation + audience** : interviews 5 cibles + setup canal de capture.
- **S2 — Ébauche asset** : MVP (formation 3 modules / template unique / SOP / plugin / landing SaaS no-code).
- **S3 — Test** : 3-5 early adopters testent, feedback.
- **S4 — Soft launch** : pricing + page de vente simple + beta payante ou pré-order.

---

## Règles universelles applicables sur TOUS les plans

1. **Pas de J+X ambigu** : chaque action doit être exécutable par un freelance normal en temps imparti. Si tu doutes de la faisabilité → tu fractionnes.
2. **Chaque action a un livrable mesurable** : un fichier, un email envoyé, un chiffre noté, une ligne publiée. Pas de "réfléchir à" ou "explorer".
3. **Si Q5 ≤ 3h/semaine** : compresse S2-S3-S4 à 2 actions max par semaine. Plan "mode minimum viable". Signale au freelance.
4. **Si Q13 bloque une action proposée** (ligne rouge) : tu la remplaces par un équivalent respectant la contrainte. Jamais passer outre.
5. **Ne pas suggérer un outil que le freelance n'a pas ou ne connaît pas** sans en préciser l'apprentissage dans l'action elle-même (ex: "J+4 : installer + configurer Framer, 1h").
6. **Si Stack Blueprint existe** : aligner les outils proposés sur la stack déjà décidée pour éviter la duplication.
