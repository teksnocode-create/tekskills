# Assets "marketing qui prouve" — exemples par profil métier

> Objectif de cette référence : donner des exemples concrets d'assets Niveau 1/2/3 calibrés par métier pour que Stack Builder ne ressorte jamais des généralités type "fais un post LinkedIn sur l'IA".
>
> Règle absolue : chaque asset doit montrer un **livrable vrai** ou un **process vrai**. Aucun asset aspirationnel toléré.

---

## Principes transversaux

### Le "how" bat le "wow"

Un post qui dit "j'ai fait ce site en 2h avec l'IA, regardez le résultat !" convertit moins qu'un carrousel qui montre les 5 étapes : brief → prompt → itération → ajustement humain → livraison. Le "how" rassure le client (il comprend la méthode), défend le prix (il voit le travail humain) et crée de l'autorité (il apprend quelque chose).

### 3 règles qui tuent le tool-porn marketing

1. **Pas de "j'ai testé 50 outils IA"** — le freelance doit avoir UNE stack maîtrisée, pas une curiosité boulimique.
2. **Pas de post sur des outils qu'on n'utilise pas** — le client veut savoir ce qui est dans TA boîte, pas dans le top trends.
3. **Pas de "l'IA va tout changer"** — trop vague, zéro différenciation, écrit par 10 000 autres. On parle de SON offre.

## CODE

### Niveau 1 — Preuve instantanée (≤ 3 jours)
- **Option A — Repo public commenté** : forke un projet existant, ajoute une feature avec IA assist (Cursor, Claude Code), commit avec commits messages qui montrent les prompts utilisés. Partage le lien + 1 post expliquant la démarche.
- **Option B — Démo vidéo 90 sec** : screen recording d'une session "brief → specs → scaffolding → 1 feature". Upload Loom ou YouTube Short. Titre : "Comment je code une [feature X] en 20 min avec Claude Code".
- **Option C — Mini-tool gratuit** : un outil utile à ta cible (ex: "JSON formatter spécialisé React" pour dev React). Déployé sur Vercel, open-source sur GitHub, post de lancement.

### Niveau 2 — Preuve récurrente
- **Série LinkedIn "Vendredi, je refais"** : chaque vendredi, tu refais une feature d'une app connue en 1h avec IA, tu publies le code + vidéo + retex.
- **Newsletter "1 pattern IA par semaine"** : 1 pattern concret (agent ReAct, tool use, prompt chain) expliqué sur un cas code réel.
- **Thread hebdo sur X/LinkedIn** : "Cette semaine j'ai gagné Xh en utilisant [pattern concret]".

### Niveau 3 — Preuve structurelle
Page portfolio `/ia-augmente` avec 2-3 études de cas format :
- **Problème** : "Client e-commerce, 500 produits, pas de fiches SEO"
- **Méthode IA** : "Pipeline Airtable → Claude API (batch processing) → Webflow CMS"
- **Résultat** : "500 fiches produits uniques, validées humain, publiées en 4 jours"
- **Temps gagné** : "Avant = 3 semaines estimées. Après = 4 jours. Facturation : 50% du tarif initial, marge doublée."

## DESIGN

### Niveau 1 — Preuve instantanée (≤ 3 jours)
- **Option A — Avant/après process** : post carrousel montrant moodboard IA → itération Figma → livrable final. Commente chaque étape avec les prompts Midjourney utilisés (ou autre).
- **Option B — Rebrand fictif 2h** : prends une marque locale peu connue, fais un rebrand complet en 2h streaming-style, publie un Reel de 60 sec.
- **Option C — Template gratuit Figma** : un kit Figma qu'ils peuvent remixer, lié à un post qui explique comment tu l'as construit avec IA.

### Niveau 2 — Preuve récurrente
- **Série "Design decision" sur Instagram/Dribbble** : 1 choix de design par semaine justifié publiquement avec le process IA-assisté qui a mené à la décision.
- **YouTube Shorts "60 secondes de process"** : vidéo courte montrant une étape précise (ex: "Comment je génère un moodboard 3× plus vite avec Midjourney + Figma").

### Niveau 3 — Preuve structurelle
Page portfolio avec 2-3 case studies format :
- **Problème** : "Client SaaS, besoin landing page, budget serré, deadline 1 semaine"
- **Méthode IA** : "Brief Claude pour extraction messaging → Midjourney 20 variations hero → itération Figma → dev Framer"
- **Résultat** : "Landing live J+5, A/B testée, conversion 4,2%"
- **Temps gagné** : "Brief + moodboard passé de 8h à 2h, soit 75% de réduction sur cette phase."

## MOTS

### Niveau 1 — Preuve instantanée (≤ 3 jours)
- **Option A — Avant/après brief client** : publie un brief client (anonymisé) + ton livrable + le temps passé + une ligne sur comment l'IA a été utilisée (sans fétichiser). Post LinkedIn.
- **Option B — Teardown d'une page web** : refais le copy d'une landing célèbre en 30 min avec IA-assist, publie en side-by-side.
- **Option C — Mini-guide "5 prompts pour [verbe d'action cible]"** : téléchargeable sur une landing, capture d'email en échange.

### Niveau 2 — Preuve récurrente
- **Newsletter "1 brief réel / semaine"** : chaque semaine, 1 commande client anonymisée + ton plan de production + IA-usage + livrable final. Le client voit ton cerveau à l'œuvre.
- **Thread LinkedIn hebdo "Ce que j'ai changé dans mon process cette semaine"** : micro-ajustements IA commentés.

### Niveau 3 — Preuve structurelle
Page portfolio avec études de cas format :
- **Problème** : "Fondateur tech, pas de voice écrite, besoin de 15 posts LinkedIn/mois"
- **Méthode IA** : "Interview 1h → Claude extraction de voice → template de rédaction IA-assisté → humanisation manuelle"
- **Résultat** : "15 posts/mois livrés, voice validée par le fondateur, engagement +X%"
- **Temps gagné** : "Temps de production par post : 45 min → 15 min, à qualité équivalente."

## CONSEIL

### Niveau 1 — Preuve instantanée (≤ 3 jours)
- **Option A — Mini-analyse publique** : prends une actualité sectorielle (pertinente pour ta cible) et publie une analyse en 5 points IA-assistée (NotebookLM sur les sources + ton commentaire). Démontre le cerveau + la méthode.
- **Option B — Diagnostic gratuit** : propose un audit flash (30 min) sur 3 profils, publie un extrait anonymisé du résultat avec le process IA derrière.
- **Option C — Frameworks visuels** : un framework de décision (PDF 1 page) que ta cible peut utiliser, construit avec IA.

### Niveau 2 — Preuve récurrente
- **Newsletter hebdo "1 cas + 1 décision"** : chaque semaine, 1 situation client (anonymisée) + le cheminement de décision avec l'IA dans la boucle.
- **LinkedIn "Lundi matin reasoning"** : chaque lundi, tu partages ton process de reflexion IA-assisté sur un sujet sectoriel.

### Niveau 3 — Preuve structurelle
Page portfolio avec études de cas format :
- **Problème** : "CEO scale-up 50 personnes, perte de focus produit, 6 mois de retard roadmap"
- **Méthode IA** : "Interviews équipe (30) → synthèse Claude → pattern detection → restitution + framework de priorisation"
- **Résultat** : "Roadmap resserrée à 3 initiatives, equipe alignée, shipping repris en 6 semaines"
- **Temps gagné** : "Phase d'écoute & synthèse : 3 semaines → 5 jours."

## OPS

### Niveau 1 — Preuve instantanée (≤ 3 jours)
- **Option A — Workflow montré** : capture d'un scenario Make/n8n que tu as fait pour un client (anonymisé) + 1 post qui explique le ROI en heures gagnées.
- **Option B — Template Notion offert** : un hub Notion opérationnel (dashboard freelance, tracker client) téléchargeable, construit avec IA.
- **Option C — Loom de 3 min** : "Comment j'ai automatisé X pour un client cette semaine", vidéo screen.

### Niveau 2 — Preuve récurrente
- **Série "Mardi automation"** : chaque mardi, 1 automation publiée (workflow Make/n8n screen + explication + ROI) sur LinkedIn.
- **YouTube channel "Build in public"** : 1 vidéo/semaine d'une automation complète de A à Z.

### Niveau 3 — Preuve structurelle
Page portfolio avec études de cas format :
- **Problème** : "Agence web, onboarding client chaotique, 5h perdues par nouveau client"
- **Méthode IA** : "Airtable base + formulaire Tally + Make scenario + docs Notion auto-générés via Claude"
- **Résultat** : "Onboarding automatisé en 20 min, 0 oubli, pipeline suivi à 100%"
- **Temps gagné** : "5h → 20 min par client, soit 14× plus rapide."

## IMAGE

### Niveau 1 — Preuve instantanée (≤ 3 jours)
- **Option A — Before/after post-prod IA** : un rush brut vs rendu IA-boosté (transcription auto, cut auto, étalonnage), en split-screen vidéo 60 sec.
- **Option B — Short "les 3 IA que j'utilise tous les jours"** : screencast ultra court de ta stack concrète (Descript, Runway, etc.).
- **Option C — Template réutilisable** : un LUT + transitions CapCut exporté, téléchargeable, avec 1 post de lancement.

### Niveau 2 — Preuve récurrente
- **Série "Montage dimanche"** : chaque dimanche, tu publies un extrait de montage avec la méthode IA utilisée.
- **YouTube longue forme mensuelle** : 1 vidéo/mois "comment j'ai monté [projet client] avec l'IA dans la boucle".

### Niveau 3 — Preuve structurelle
Page portfolio avec études de cas format :
- **Problème** : "Podcaster, 10h de dérushage par épisode, limite le rythme de publication"
- **Méthode IA** : "Descript pour transcription + cut + remove silences → DaVinci pour color + livraison"
- **Résultat** : "Dérushage passé de 10h à 2h par épisode, rythme passé de mensuel à hebdo"
- **Temps gagné** : "5× plus rapide sur dérushage, permet de shipper 4× plus de contenu."

## Adaptation selon Q10 (heures dispo)

- **< 3h/semaine** : Niveau 1 uniquement + 1 asset Niveau 2 bi-mensuel (pas hebdo). Niveau 3 différé à J+30.
- **3-5h/semaine** : Niveau 1 + Niveau 2 hebdo. Niveau 3 prévu à J+14.
- **> 5h/semaine** : Niveau 1 + Niveau 2 hebdo + démarrage Niveau 3 dès J+7.

## Adaptation selon Q13-14 (preuves existantes)

- **Q13 = 0 et Q14 = aucune** : priorise Niveau 1 (urgence de créer un 1er asset, même imparfait). Niveau 3 à plus long terme.
- **Q13 ≥ 3 mais Q14 = aucune** : priorité Niveau 3 (il a la matière, il manque la mise en scène IA). Niveau 1 = retraitement d'une étude de cas existante avec angle IA.
- **Q13 ≥ 3 et Q14 ≥ 1** : accélère sur Niveau 2 (structure la récurrence, il est déjà crédible).
